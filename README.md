# Pancreatectomy Diabetes Predictor

Source code for prediction Web App.

To build, clone the repository, containerise with Docker and deploy.

To run the app locally, use 'streamlit run App.py' in the downloaded repository (this requires the Streamlit library for Python 3).

See [pancpred.azurewebsites.net](pancpred.azurewebsites.net) for live app.

Details of predictive model to be published shortly.
